🚀 Invisible Utility Mapping (IUM) - MuniAR
**Empowering Urban Infrastructure with AR X-Ray Vision.**
📌 Project Overview
**MuniAR** is an Augmented Reality (AR) solution designed to visualize underground utilities (water pipes, gas lines, electrical cables) in real-time. By transforming complex geospatial data into an intuitive 3D AR overlay, we aim to prevent accidental utility damage during excavations and streamline urban maintenance.
### 🌟 Key Features
 * **AR X-Ray Vision:** High-precision visualization of underground assets directly on the mobile screen.
 * **Real-time Mapping:** Uses ARCore/ARKit to anchor digital infrastructure models to real-world coordinates.
 * **Utility Insights:** Tap on any virtual pipe to see its material, depth, and installation date.
 * **Interactive UI:** Clean, futuristic dashboard for field engineers and municipal workers.
* **Version Control:** Git & GitHub
